# 跨国展览成果释出协调

本仓库实现中埃联合考古成果释出协调服务：把发掘单元、文物对象、原始记录、解释主张、贡献人、翻译稿、借展条款、禁发期与公开载体连成可追踪关系，协调考古队、借展机构与策展团队对照片、测量数据和初步解释的公开节奏，避免提前释出影响未发表研究或借展信任。

## 目录

- `contracts/domain.schema.json`：领域对象与事件名称约定。
- `data/sample.json`：一条可用于本地联调的示例事件。
- `src/envelope.py`：事件信封的基础字段与类型校验。
- `src/errors.py`：领域错误。
- `src/model.py`：由事件流重建的状态投影。
- `src/store.py`：追加式事件存储（JSONL 持久化与回放）。
- `src/service.py`：释出协调服务（命令、会签、发行、撤展、待办、追溯）。
- `src/cli.py`：检查 JSON 事件文件的命令入口。
- `tests/`：信封、契约、工作流与协调规则的回归测试。

## 领域约定

当前交换协议覆盖研究数据、双边会签和禁发期限。事件标识一旦接收不得原地复用为另一份内容，版本必须为正整数，时间采用带时区的 ISO 8601 格式。业务修订通过新的事件表达，原始记录继续用于追溯。

## 协调流程

- **释出申请**：研究者提交方案时冻结引用的数据版本（`id` 冻结当前版，`id@版本` 冻结指定版），借展条款在此把关。相同申请重试复用原流程；内容变化必须新建版本，旧版本的确认不带入。
- **双边会签**：中埃双方数据责任人分别确认当前冻结版本，并发批准也不会越过任一方；内容变更后需基于最新版本重新确认。
- **公开版本**：策展编辑只能在批准范围内生成面向公众的版本，引用必须标注版本；禁发期与撤展状态在发行时把关。
- **不确定性与更正**：初步结论可标注不确定性；后续修订以更正关联旧版，曾经展出的内容不被覆盖，旧版追溯仍指向当时有效的结论。
- **局部撤展**：文物临时撤展只暂停依赖实体展示条件的载体（如展签），图录、论文等非实体载体与已获准的学术事实不受影响；复展后自动恢复。
- **独立待办**：贡献人异议、翻译争议、禁发期延长各有独立待办，互不影响；禁发延期在待办批准后才生效，已发布内容不回撤。
- **恢复与追溯**：事件全部落盘，服务恢复后继续未完成的会签；`trace_variant` 可从一句展签追到数据来源、翻译、许可、贡献署名和当时有效的研究结论。

## 本地运行

检查示例事件：

```bash
python3 -m src.cli data/sample.json
```

运行测试：

```bash
python3 -m unittest discover -s tests
```

编译检查：

```bash
python3 -m compileall -q src tests
```

这些命令只使用 Python 标准库，不需要单独运行数据库或其他服务。事件存储传入文件路径即持久化（如 `EventStore("events.jsonl")`），省略路径则为纯内存运行。
